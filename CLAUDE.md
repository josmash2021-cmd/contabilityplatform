## The product
Spanish-first (also English) accounting SaaS for Hispanic small businesses and personal finances in the US.
Live: https://aethelaccountingplatform.com · repo folder `contabilityplatform` · Railway deploys `main`.
- Two modes per account: **business** (sales/POS, invoices, quotes, customers, vendors, expenses, receipts, bank, reports, accountant, team, assistant, taxes) and **personal** (bank, transactions, budgets, goals, subscriptions, assistant, taxes).
- Plans: business Básico / Pro / Negocio, personal Básico (free) / Pro; 7-day free trial, no card. Rules live in `contracts/planFeatures.ts` (single source); prices in `src/components/marketing/content.ts` must match `api/lib/plans.ts`.
- Tax prep is **free** for the client, **Alabama only**, documents encrypted in the DB (`TAX_FILES_KEY`).
- Public site: `/` (landing when signed out), `/producto`, `/como-funciona`, `/seguridad`, `/precios`, `/preguntas`, `/privacy`, `/terminos` (= `/terms`, tax service terms) and `/terminos-de-uso` (= `/terms-of-use`, the app's own terms, `src/i18n/copy/termsOfUse.ts`); both are drafts the owner should have a lawyer review. Their public contact address (and the Privacy Policy's) is `CONTACT_EMAIL` in `contracts/constants.ts` (team@personalandbusinesssolution.com; an address can't have "&" after the @). The owner's own admin login (`OWNER_EMAIL` in `api/auth-router.ts`) is a different thing: never change it. The legal pages' back arrow uses `useBack()` (`src/hooks/useBack.ts`): opened on their own it goes home. Sign-in: `/login`, `/register`, `/forgot-password`, `/join`.
- Admin (role `admin`): its own shell `src/components/layout/AdminLayout.tsx` (menu Resumen, Usuarios, Pagos, Impuestos, Soporte, Bloqueados, Sistema + "Volver a mi cuenta"; phones: bottom bar + Más), not the business app's. `/admin` = Resumen (`AdminHome.tsx`: 4 numbers, weekly chart, Para hoy, newest users, activity), `/admin/usuarios` and `/admin/bloqueados` (`AdminUsers.tsx`, filters `?estado=trial|paying|failed|canceled|free`, `?q=`), the person's card `AdminUserSheet` (payments, banks, team, taxes; Escribirle, Dar más días gratis, Regalar acceso, Cambiar a Personal/Negocio (`admin.setMode`: the only way to change an account's type, chosen at sign-up; nothing is deleted; blocked for admins and, to Personal, for team members or owners with a team; the person signs out and in again), Bloquear, Borrar), `/admin/sistema` (`AdminSystem.tsx`: services + maintenance mode: switch (asks first), optional message, "¿Cuándo vuelve?" 15 min–2 h, "Ver cómo lo ven tus clientes" preview), `/admin/ingresos` = Pagos (`AdminPayments.tsx`: 4 numbers, filters, payments by month; each payment's source from `paymentSource` in adminOverview.ts: stripe (has a Stripe invoice/intent id; receipt link), manual (written down by the admin: Zelle, cash), gift (the `ADMIN_GRANT_` row) or test (before REVENUE_SINCE); only paid stripe/manual count; only manual/test can be edited or deleted, enforced in `updatePayment`/`deletePayment`), and the older pages inside the same shell: `/admin/suscripciones` (AdminDetail), `/admin/impuestos`, `/admin/soporte`, `/admin/actividad/:id`. Every number comes from ONE rule per person, `userStatus` in `api/lib/adminOverview.ts` (admin, blocked, trial, paying, gift = `ADMIN_GRANT_` access (not income), failed, canceled, free, ended) so counts add up; `admin.overview` / `admin.userDetail` / `admin.extendTrial` in `api/admin-router.ts`; Alabama days/weeks (Monday). More free days: `trialExtensions` table (`api/lib/trialExtensions.ts`), read by `getTrialInfo(createdAt, now, until)` in `getPlanContext` and `subscription.status`. Words: `src/i18n/copy/admin.ts`. ## Owner's standing rules (always)
- Talk to the owner, write step descriptions and commit messages **in Spanish**. Code comments stay in English.
- **Show before publishing** (owner's rule since 2026-11-23): after verified work on the local server, show real screenshots (an artifact page, phone and computer) and wait for the owner's OK. Then commit and push to **both** `origin feat/funciones-planes` and `origin feat/funciones-planes:main`, wait for the Railway deploy (`railway deployment list --json`) and check `https://aethelaccountingplatform.com/api/health`.
- **Ask first** before touching production data. Never `drizzle-kit push`/recreate against production. `TAX_FILES_KEY` must never change. Never paste secrets.
- Production's database can't be reached from here: the app uses the internal `MYSQL_URL`; the public `DATABASE_URL` proxy closes the connection, and going into the server (`railway ssh`) is blocked unless the owner allows it. Account changes go through the admin (e.g. Cambiar a Personal/Negocio in the person's card).
- Design must look **modern and current** (soft shadows, rounded shapes, eased motion, modern cursors/icons). Nothing dated.
- Copy: no « » or similar marks; no government logos/seals (IRS, Alabama); bank/merchant logos are real modern PNGs in `public/brands/`; Excel/PDF logos via `src/components/FileLogo.tsx`.
- Public site and sign-in pages block zoom (`src/hooks/useNoZoom.ts`); the app allows zoom.

## Patterns to follow
- **Words**: every UI string in `src/i18n/copy/*.ts` as `{ es, en }` (type = `typeof es`), read with `useCopy(dict)`; server messages via `msg(lang, key)` in `api/lib/i18n.ts`; language comes in the `x-lang` header.
- **Language is automatic** (owner's choice, 2026-11-23): Spanish when the phone/computer is in Spanish (`navigator.languages`), English otherwise (`src/i18n/lang.ts`). There is NO ES/EN switch on the site or sign-in pages (`LanguageSwitcher` was deleted); only Perfil > Idioma inside the app (`Sections.tsx` → `setLang`) overrides it, saved under `localStorage "lang_pref"` (the old switch's `"lang"` key is ignored on purpose). Tests set `lang_pref`; check with `browser/cdp-autolang-body.mjs` (38 checks: es/en devices, every page, phone menu).
- **New tables**: created on first use with `CREATE TABLE IF NOT EXISTS … ENGINE=InnoDB DEFAULT CHARSET=utf8mb4` inside an `ensure…Tables(db)` promise, queried with raw `db.execute(sql…)`. Raw rows: use `rowsOf()`; times come back as `"YYYY-MM-DD HH:MM:SS"` text in UTC, convert with `utcDate()` (`api/lib/support.ts`) before sending to the browser. When an account is deleted (`api/admin-router.ts` deleteUser) its rows must go: add the table to `USER_TABLES` (`api/lib/userDataCleanup.ts`) or a `deleteUser…Data` call.
- **Claude**: model `claude-opus-5-5`, `output_config: { effort: "low" }` for chat answers.
